# Richard J. Allen — Professional Website Distribution Checklist

Canonical website:
https://richard-allen-professional-portfoli.vercel.app/

## Trigger
Use this checklist only after final production QA is complete, temporary QA routes/files are removed, and the canonical site passes factual/privacy/accessibility checks.

## Highest-priority placements
- LinkedIn Contact Info: add as Website / Portfolio.
- LinkedIn Featured: feature the professional portfolio with a concise recruiter-facing label.
- LinkedIn About: include the portfolio URL once, naturally, near the end rather than repeating it.
- General / Master resume: add a clickable Professional Portfolio link in the contact header.
- ATS resume: include the plain-text canonical URL in the contact header while keeping formatting ATS-safe.
- Tailored resumes: inherit the portfolio link unless an employer explicitly requests otherwise.
- Upwork profile: add the portfolio link wherever Upwork permits an external professional website/portfolio link without violating platform rules.
- Upwork Project Catalog / portfolio materials: cross-reference the website only where permitted and useful; do not replace the Upwork service CTA with an off-platform solicitation.

## Application and recruiter placements
- Application forms: use the URL in Website / Portfolio / Personal Website fields.
- Cover-letter template: make the URL available in the header/contact block when appropriate; do not force it into every letter body.
- Recruiter email signature: include Professional Portfolio as a single clean link.
- Recruiter outreach / networking messages: use selectively when the recipient would benefit from seeing work examples.
- Interview follow-up: include when referencing case studies, work samples, or additional background.

## Professional-profile placements to review
Only update profiles Richard actually uses.
- Indeed profile / resume profile
- ZipRecruiter profile
- Glassdoor profile if actively used for applications
- Dice or other technology/job-market profiles if actively used
- Staffing-agency candidate profiles that provide a Website / Portfolio field
- Professional association profiles or directories relevant to target roles
- GitHub profile README or profile bio only if it supports the professional story and does not imply Richard is seeking software-development roles

## Owned channels
- Career Gmail signature
- Professional email templates
- Professional PDF resumes exported from the master resumes
- Any future business card / QR code / networking handout
- Upwork proposal template where linking is permitted and relevant

## Use with restraint
Do not add the URL to:
- personal/social profiles unrelated to employment unless Richard explicitly wants it there;
- every paragraph of LinkedIn or resumes;
- application answers that do not ask for or benefit from a portfolio;
- platforms whose rules prohibit off-platform links or solicitation;
- private/community profiles where professional-job-search visibility is unwanted.

## Quality standard before distribution
- Canonical production URL returns 200.
- Mobile and tablet QA complete.
- Temporary viewport-QA routes/files removed.
- Public phone remains omitted unless Richard changes the privacy rule.
- Career email and LinkedIn links work.
- Resume education, titles, dates, and metrics agree with the Career Master Facts & Accomplishment Bank.
- No private pastoral, youth, household, legal, medical, or unnecessary religious details exposed.
- Full-time job search remains primary; freelance/project work remains secondary.
